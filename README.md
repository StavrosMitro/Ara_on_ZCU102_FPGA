# Cheshire + Ara on the ZCU102

This fork of [Cheshire](https://github.com/pulp-platform/cheshire) runs CVA6 with
the [Ara](https://github.com/pulp-platform/ara) RISC-V vector unit on a Xilinx
**ZCU102**. CVA6 + Ara runs bare-metal programs from the PS DDR. The ARM PS
loads them and reads their output.

The FPGA configuration is FP16-oriented (no FP64, scalar or vector) and has an
LLC with SPM ways and an iDMA. Lanes, VLEN, LLC size, vector FPU precision,
clocks and ILA probes are all build-time knobs.

- **[Building bitstreams and apps](docs/zcu102/building.md)**: requirements, sources, build knobs, sweep scripts, app toolchain
- **[Running on the board](docs/zcu102/running.md)**: console, JTAG programming, SD card, loading, reading results, pitfalls

## Repository layout

| Path | Contents |
|---|---|
| `hw/`, `target/xilinx/` | Cheshire SoC, ZCU102 top level, constraints, Vivado scripts |
| `deps/ara/` | submodule → [ara_zcu102_working](https://github.com/StavrosMitro/ara_zcu102_working): the Ara RTL that gets built, the build-knob Makefile (`deps/ara/cheshire/`), the bare-metal apps (`deps/ara/apps/`) |
| `cva6_patched/`, `axi_patched/`, `idma_patched/` | patched CVA6, AXI and iDMA, used instead of the upstream versions through `Bender.lock` |
| `tools/zcu102/` | JTAG programming script, SD-card helper scripts, DDR loader, unattended sweep runner |

## Quick start

```bash
git clone https://github.com/StavrosMitro/cheshire_ara.git && cd cheshire_ara
git submodule update --init deps/ara
bender checkout
cd deps/ara/cheshire
make ara-chs-xilinx BOARD=zcu102 MODE=batch VIVADO=vivado nr_lanes=4 vlen=2048 llc=1024
#  -> target/xilinx/out/cheshire.zcu102.bit
```

## Cheshire

Cheshire is a minimal Linux-capable host platform built around the RISC-V [CVA6](https://github.com/openhwgroup/cva6) core. Its goal is to provide a *lightweight*, *configurable*, *autonomously booting* host to systems that need one, from minimal Linux-capable SoCs to manycore compute accelerators.

Cheshire is developed as part of the PULP project, a joint effort between ETH Zurich and the University of Bologna.

### Quick Start

* To learn how to build and use Cheshire, see [Getting Started](https://pulp-platform.github.io/cheshire/gs/).
* To learn about available simulation, FPGA, and ASIC targets, see [Targets](https://pulp-platform.github.io/cheshire/tg).
* For detailed information on Cheshire's inner workings, consult the [User Manual](https://pulp-platform.github.io/cheshire/um/).

If you are impatient and have all needed [dependencies](https://pulp-platform.github.io/cheshire/gs/#dependencies), you can run `make all`, then start QuestaSim in `target/sim/vsim` and run a [simulation](https://pulp-platform.github.io/cheshire/tg/sim) by typing:

```
set BINARY ../../../sw/tests/helloworld.spm.elf
source compile.cheshire_soc.tcl
source start.cheshire_soc.tcl
run -all
```
